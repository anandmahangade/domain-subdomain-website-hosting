# Domain and Subdomain-Based Website Hosting

## Project Overview

This project demonstrates website hosting using a custom domain name and subdomains. It includes hosting an Axom Car website using a domain name, hosting another version using a subdomain, and hosting an e-commerce website using a subdomain.

**Main Domain:** `cloudwala.online`

## Project Objectives

- Understand domain names and DNS configuration.
- Host websites using a custom domain.
- Configure subdomains for separate websites.
- Learn the fundamentals of web hosting and website accessibility.

## Websites Included

### 1. Axom Car — Main Domain
Host the Axom Car website using the configured domain name.

### 2. Axom Car — Subdomain
Host the Axom Car website using a separate subdomain.

### 3. E-commerce Website — Subdomain
Host an e-commerce website using its own subdomain.

## Technologies and Concepts

- Domain Name System (DNS)

- Website hosting
- Web server configuration (if used)
- Linux and Nginx (if used)
